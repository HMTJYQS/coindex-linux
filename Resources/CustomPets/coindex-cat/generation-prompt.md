# Coindex Cat artwork

Original generated black-and-white cat illustration used as the default desktop companion. No reference photographs are included in this repository.

The rendered source atlas is packed into a 1536 × 2288 transparent sprite sheet with 192 × 208 cells, 8 columns, 11 rows and 73 occupied frames. Rows cover idle, right/left walking, waving, jumping, failed, waiting, reviewing, running and 16 gaze directions. See `generation.json` for frame bounds and checksums. Repack with `scripts/pack-pet-atlas.py`; Pillow is needed only for that optional asset tool.
